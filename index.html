03 / Ball measurements

Guided estimates, not automatic ball detection. Trace only points where you can see the ball.

Trace: pause, tap ball, advance, repeat. Scale: use two known points in the same plane. Turn: incoming ground-line point → bounce → outgoing ground-line point. Perspective distorts angles; use a near-overhead view for a usable estimate.

Speed = supplied ground distance ÷ marked flight time: average ground-projected speed, not release speed. No 3D trajectory or spin RPM is inferred.
